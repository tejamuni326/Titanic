# Titanic Survival Prediction

## Machine Learning + Deep Learning Project

This project predicts whether a Titanic passenger survived the disaster using Machine Learning and Deep Learning models.

The project uses the Titanic dataset and provides an interactive Streamlit application for making survival predictions.

---

## Project Objective

The objective of this project is to build and compare multiple Machine Learning and Deep Learning models for Titanic survival prediction.

The project includes:

- 5 Machine Learning models
- 2 Deep Learning models
- Model performance comparison
- Selection of the best Machine Learning model
- Streamlit web application for prediction

The target variable is:

- `0` = Did not survive
- `1` = Survived

## Dataset

The Titanic dataset contains passenger information and the target variable `Survived`.

### Features Used

| Feature | Description |
|---|---|
| Pclass | Passenger class |
| Sex | Passenger gender |
| Age | Passenger age |
| SibSp | Number of siblings/spouses aboard |
| Parch | Number of parents/children aboard |
| Fare | Passenger fare |
| Embarked | Port of embarkation |
